# R2-A1-ToolResult 承载边界设计（ToolExecutionRecord + ToolResultV2 草案）

**日期**：2026-08-21
**状态**：DESIGN（仅设计，未实施）
**目标**：消除平行 `tool_result.ToolResult`（9 个 V2 业务字段）作为"跨语言合同"的越权，明确内部业务载体（`ToolExecutionRecord`）与权威 wire 模型（`contracts.ToolResult` V1 15 字段）的边界，为 Phase 10 持久化打基础。

---

## 1. 现状矛盾

权威 `contracts.ToolResult`（V1 wire，15 字段，对齐 Python/TS/Go + fixture）：
```text
tool_name, cluster_id(UUID), success, status, summary, data,
error_code, error_message, retryable, evidence_ids(List[UUID]),
source_system, query_id, time_range, started_at, finished_at
```
平行 `tool_result.ToolResult`（业务内部，含 9 个 V2 字段）：
```text
+ tenant_id, tool_id, request_id, retry_policy, evidence_required,
  duration_ms, provenance, partial_reason, denied_scope
```

**问题**：平行 `ToolResult` 被当作业务主模型消费（agent_runtime/evidence_hub/security_gate/test_p73），
但其 9 个 V2 字段不在权威 wire（Python/TS/Go）中，形成"伪合同"越权；同时 `normalize_tool_result`
返回平行模型，未消费方全切到权威。

---

## 2. 承载边界设计（Y2 同构）

```text
ToolExecutionRecord（内部业务载体，非 wire）
  tool_name / status / summary / data / ... 15 个权威字段 + 9 个 V2 业务字段
        │  ACL.to_contract（15 字段投射 + UUID 规范化）
        ▼
contracts.ToolResult（V1 权威 wire，15 字段，唯一跨语言合同）
        │
        ▼
ToolResultV2（草案，仅当 V2 字段必须上 wire 时才设计，不暗改 V1）
```

**核心原则**：
- `contracts.ToolResult` 是**唯一跨语言 wire 模型**（V1 15 字段冻结，不暗改）。
- `ToolExecutionRecord`（原平行 `tool_result.ToolResult` 改名）是**内部业务载体**（非 wire），
  承载 15 字段 + 9 个 V2 审计/业务字段。
- 9 个 V2 字段**不重新塞回 V1**；如需上 wire，走独立 `ToolResultV2` 草案（wire_version 大版本）。
- ACL 只做临时转换边界（15 字段投射），所有调用方切换完成后删除。

---

## 3. ToolExecutionRecord（改名后的内部载体）

```python
@dataclass
class ToolExecutionRecord:
    """内部业务载体（非跨语言合同）。承载 V1 权威字段 + V2 内部审计字段。"""
    tool_name: str
    tool_id: str            # V2
    cluster_id: str
    tenant_id: str          # V2
    status: str
    summary: str
    data: Dict[str, Any]
    error_code: str
    error_message: str
    retryable: bool
    retry_policy: Dict      # V2
    evidence_ids: List[str] # 内部引用（ACL 转 UUID）
    evidence_required: bool # V2
    source_system: str
    request_id: str         # V2
    query_id: str
    time_range: str
    started_at: datetime
    finished_at: datetime
    duration_ms: int        # V2
    provenance: Dict        # V2
    partial_reason: Optional[str] = None  # V2
    denied_scope: Optional[Dict] = None   # V2

    def to_dict(self) -> Dict[str, Any]: ...  # 内部审计用，非 wire 序列化
```

**改名影响**：
- `from tool_result import ToolResult` → `from tool_result import ToolExecutionRecord`（别名兼容过渡期）。
- `isinstance(res, ToolResult)` → `ToolExecutionRecord`。
- `normalize_tool_result` 返回 `ToolExecutionRecord`。
- 消费方（agent_runtime/evidence_hub/security_gate/test_p73）字段访问不变（字段名相同）。

---

## 4. ToolResultV2 草案（仅当 V2 字段必须上 wire）

当前 **9 个 V2 字段不上 wire**（内部审计），不设计 ToolResultV2。
若未来需要（如 tenant_id 作为 wire 隔离维度），走独立草案：
```python
class ToolResultV2(ContractModel):  # 草案，wire_version=v2，独立升级，不暗改 V1
    ... V1 15 字段 ...
    tenant_id: Optional[UUID]
    tool_id: Optional[str]
    request_id: Optional[str]
    retry_policy: Optional[Dict]
    evidence_required: bool
    duration_ms: Optional[int]
    provenance: Optional[Dict]
    partial_reason: Optional[str]
    denied_scope: Optional[Dict]
```
**Gate**：V2 仅在三端（Python/Go/TS）对齐 + conformance-vectors + 独立 wire_version 后才可能升级。

---

## 5. ACL 边界

`acl/tool_result_ac.py`（既有）：`ToolExecutionRecord → contracts.ToolResult`（V1 wire）：
- 15 字段投射（`tool_id`→丢弃或 action 映射、`evidence_ids` 经 UUIDv5/实体存在校验）。
- `cluster_id` str→UUID、`status` str→ToolStatus、`time_range` str→Dict。
- **临时边界**：所有调用方切换到权威 `contracts.ToolResult` 后删除。

## 7. 实施顺序

1. `tool_result.py`：`ToolResult` → `ToolExecutionRecord`（保留 `ToolResult = ToolExecutionRecord` 别名过渡）。
2. 消费方 import 迁移（agent_runtime/evidence_hub/security_gate/test_p73）。
3. ACL 边界确认（ToolExecutionRecord → contracts.ToolResult）。
4. `test_p73` 等迁移 + 回归 + ruff。
5. T5 gate：`tool_result.ToolResult` 不再是独立平行合同（改名/别名）。

---

## 8. 验收

1. `tool_result.ToolResult` 平行 dataclass 消除（改名 `ToolExecutionRecord`，明确非 wire）。
2. 权威 `contracts.ToolResult` V1 15 字段冻结，未暗改；9 个 V2 字段在 `ToolExecutionRecord`。
3. `ToolResultV2` 草案仅在需要上 wire 时设计（当前不设计）。
4. ACL 临时边界，消费方全切后删除。
5. 完整回归 + ruff + Go 全绿。
