# 3. PI.1 Real query-api Production Integration Design

## 3.1 目标
替换 InternalQueryClient mock → Production InternalQueryClient。

## 3.2 通信模型
Agent Runtime → InternalQueryClient → mTLS → query-api /internal/v1/query/*

## 3.3 安全要求
- **mTLS**：Client Certificate（服务身份认证，防伪造 Agent Runtime）
- **Authorization**：TrustedRequestContext V3（tenant/cluster/capability/request_id/timestamp/signature）；query-api 校验 signature valid && capability allowed && tenant permitted，否则 DENY

## 3.4 Timeout / Retry
保持 Tool Registry 约束（Tool.timeout_class / Tool.retry_policy）；禁止 Agent 修改 timeout/retry/backoff。

## 3.5 Audit
完整链：agent_run_id → request_id → query-api audit → Evidence id（谁/什么时候/查询什么/获得什么证据）

---

# 4. PI.2 TrustedRequestContext V3 Design

## 4.1 V2 当前能力
tenant/cluster/capability/request_id/nonce

## 4.2 V3 增强
新增：issuer/timestamp/expiry/signature/key_id

```json
{ tenant, cluster, capability, request_id, nonce, issuer, timestamp, expiry, key_id, signature }
```

## 4.3 防护目标
| 风险 | 防护 |
|------|------|
| 请求伪造 | signature |
| 重放 | nonce |
| 过期请求 | expiry |
| 密钥轮换 | key_id |
| 跨租户访问 | tenant |

---

# 5. PI.3 ResourceGraph Production Data Integration Design

## 5.1 当前状态
query-api topology → ResourceGraphProvider → 静态 topology

## 5.2 生产目标
数据来源：Kubernetes / OpenStack Inventory / CMDB / Network Topology；统一入口：Data Source → query-api boundary → ResourceGraphProvider → Resource Graph

## 5.3 禁止
- Agent → Kubernetes informer（禁止）
- ResourceGraph → 直接访问 CMDB（禁止）

## 5.4 Graph 生命周期增强
- **Snapshot**：graph_snapshot_id/timestamp/version
- **Incremental Update**：add node/remove node/change edge
- **Stale Detection**：last_seen/expire_time/status（避免旧拓扑=错误分析依据）
