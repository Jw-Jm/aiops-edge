## F1：LLM 非权威声明

```text
LLM can propose      // LLM 可以提议
LLM cannot authorize // 不能授权
LLM cannot expand capability // 不能扩展 capability
LLM cannot modify risk      // 不能修改风险等级
```

LLM 是推理/提议组件，**不是权限权威**。权限只能来自 MySQL SoT / Tool Registry / 用户显式授权。

---

## F2：三个身份永久分离

```text
User Identity      !=  // JWT user 身份
Service Identity   !=  // 服务工具访问身份
Execution Identity     // 运行执行上下文
```

JWT(user) ≠ execution permission。三者不得合并，避免权限膨胀。

---

## F3：Evidence ≠ Diagnosis

```text
Evidence  → fact（事实）
Planner   → hypothesis（假设/评分）
Execution → future phase（后续阶段）
```

Evidence 只记录查询事实，不产出诊断结论；Planner 产出假设；执行属后续阶段。

---

## F4：Planner 不拥有 Tool

```text
Planner ──select──→ Registry ──authorize──→ Tool
```

Planner 只能**选择** Registry 中已注册、cluster 可用、capability 允许的 Tool；**不拥有** Tool，
不能定义/修改 Tool metadata/capability/risk。

---

## F5：Phase7 End State

```text
Phase7 输出：
  Plan Proposal
  + Evidence Package
  + Approval Request

不是：
  Change Execution
```

Phase7 的终止产物是"计划 + 证据包 + 审批请求"，**不是**变更执行。
