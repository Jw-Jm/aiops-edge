## 1. P7.10 Security Contract

横切所有 Phase7 域（P7.1-P7.9）。核心：Agent 不能扩展权限、不能绕过 approval、不能越 cluster。

### 边界

| 允许 | 禁止 |
|------|------|
| 经已注册 Tool + capability gate 查询 | LLM 修改 Tool risk/read_only |
| 当前 Run scope 内查询 | wrong capability 调用 |
| tenant/cluster 隔离 | cross-cluster Tool 调用 |
| TrustedRequestContext V2 + audit | 绕过 query-api authorization |

## 2. Negative Tests（P7.10 必列）

P7.10 明确要求的 negative tests：

```text
unregistered Tool
LLM 修改 risk/read_only
wrong capability
cross-cluster Tool
budget exceeded
ambiguous target
backend unavailable
permission denied
unknown/unregistered canonical cluster
registered mapping points to wrong canonical cluster
```

---

## 3. Gate 7 追加断言（§4236-4240 附近）

```text
LLM cannot change Tool risk/read_only
cross-cluster Tool call rejected
ToolResult status exact
Planner budget exact
```

---

## 4. Test Plan（P7.10）

### T1 越权拒绝

- [ ] unregistered Tool → 拒绝
- [ ] LLM 修改 Tool risk/read_only → 拒绝（immutable）
- [ ] wrong capability（logs.read 调 metrics）→ 拒绝

### T2 Cross-Cluster / Scope

- [ ] cross-cluster Tool 调用 → 拒绝
- [ ] 未知/未注册 canonical cluster → fail-closed
- [ ] registered mapping 指向错误 canonical cluster → 拒绝

### T3 Budget / 语义

- [ ] budget exceeded → 终止（BUDGET_EXCEEDED）
- [ ] ToolResult status exact（7 态精确）
- [ ] ambiguous target → RESOURCE_AMBIGUOUS

### T4 后端语义

- [ ] backend unavailable → unavailable（不降级）
- [ ] permission denied → permission_denied（不降级 no_data）

---

## 5. 验收条件

- [ ] 全部 P7.10 negative tests 通过
- [ ] Gate 7 断言通过（LLM 不改 risk/read_only、cross-cluster 拒绝、status exact、budget exact）
- [ ] 无 scope/权限扩展路径
- [ ] 语义不降级（permission_denied/unavailable 保持）
- [ ] 所有测试（T1-T4）通过

---

## 6. 边界（当前阶段）

- ❌ 无 Go 代码 / DB migration / Helm change / Deployment / Agent execution
- ✅ 仅 Security Contract + Negative Tests + Gate 7 Assertions + Test Plan
