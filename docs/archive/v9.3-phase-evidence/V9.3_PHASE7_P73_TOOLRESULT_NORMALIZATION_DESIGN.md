## 1. P7.3 Contract

### 职责

- **统一 Tool 返回结构**：所有 Tool（P7.1 注册）经归一化产出标准 `ToolResult`。
- **语义准确**：精确区分 `success/partial/no_data/failed/timeout/unavailable/permission_denied`（§28.4 / P7.3）。
- **证据兼容**：`ToolResult → Evidence`（P7.4）映射，`evidence_ids` 建立关联。

### 边界

| 允许 | 禁止 |
|------|------|
| 精确归一化状态 | `permission_denied→no_data` |
| 保留 error_code/message | `no_data→healthy` |
| 记录 source_system/time_range | `unavailable→healthy` |
| 生成 evidence_ids（P7.4 关联） | backend 403→no_data / network error→no_data |

### 非目标（本 P7.3 不做）

- ❌ 不执行 Tool（执行在后续阶段）
- ❌ 不落 Evidence 主对象（那是 P7.4）

## 2. ToolResult Schema

```text
ToolResult {
  tool_name        string   // Tool 名称（P7.1 注册）
  tool_id          string   // Tool id
  cluster_id       string   // canonical cluster
  tenant_id        string   // canonical tenant
  status           enum     // success|partial|no_data|failed|timeout|unavailable|permission_denied
  summary          string   // 人类可读摘要
  data             object   // 结构化结果（与 output_schema 一致）
  error_code       string   // 错误码（非 success 时）
  error_message    string   // 错误详情
  retryable        bool     // 是否可重试
  retry_policy     object   // {max_attempts, backoff}（评审建议，避免无限 retry）
  evidence_ids     []string // 关联 Evidence（P7.4）
  evidence_required bool    // 是否必产 Evidence（P7.1）
  source_system    enum     // VM|VLogs|query-api|MySQL|k8sgpt|knowledge（禁止 AI/LLM/Agent）
  request_id       string   // 来自 InternalQueryClient（非 LLM 生成）
  query_id         string   // 原始查询 id（可追踪到 TrustedRequestContext/audit）
  time_range       string   // 查询时间窗
  started_at       time
  finished_at      time
  duration_ms      int      // 耗时
  provenance       object   // 溯源（评审建议 1）
  partial_reason   enum?    // partial 原因（评审建议 2）
  denied_scope     object?  // permission_denied 的 scope 信息（评审建议 3）
}
```

### provenance（评审建议 1）

```text
provenance: {
  tool_id,
  request_id,          // 与 InternalQueryClient 一致
  trusted_context_id,  // TrustedRequestContext id
  source_timestamp
}
```
建立完整链路：`ToolResult → Evidence → Plan`。

### partial_reason（评审建议 2）

```text
partial_reason: timeout_partial | source_partial | permission_partial
```

避免 `partial` 成为黑箱。

### denied_scope（评审建议 3）

```text
denied_scope: {
  required_capability,
  denied_scope
}
```
`permission_denied` 必须携带 scope 信息，供 Evidence 解释。

### status 枚举（§28.4，7 态）

```text
success            // 正常返回数据
partial            // 部分数据（部分 backend 返回）
no_data            // 查询成功但无数据
failed             // backend 查询错误
timeout            // 超时（deadline 超限）
unavailable        // backend 不可达 / 二进制缺失
permission_denied  // 授权拒绝
```

## 3. Error Semantics（归一化规则，§三十二 + P7.3）

### 正向归一化（允许）

```text
tool successful + empty result      → no_data
binary missing / backend unreachable → unavailable
authorization reject                 → permission_denied
deadline exceeded                    → timeout
backend query error                  → failed
部分 backend 成功 + 部分失败          → partial
```

### 禁止降级（P7.3 / §94 红线）

```text
permission_denied → no_data   ❌ 禁止
no_data → healthy             ❌ 禁止
unavailable → healthy         ❌ 禁止
backend 403 → no_data         ❌ 禁止
network error → no_data       ❌ 禁止
```

**原因**：降级会把权限问题伪装成无数据，导致 tenant isolation 泄露；把不可用伪装成健康，
导致根因误判。

### 重试与超时

- `retryable`：仅 `failed`/`timeout`/`unavailable` 可标记可重试（受 Tool `retry` 上限约束）
- `permission_denied`/`no_data` **不可重试**（重试无意义）
- `timeout` 由 `timeout_class`/`timeout` 控制，超限 → `timeout`（不无限等待）

## 4. Evidence Compatibility（P7.4 衔接）

`ToolResult → Evidence` 映射（P7.4 消费）：

```text
ToolResult.status    → 不进入 Evidence 状态判断（Evidence 只记录事实）
ToolResult.data      → Evidence.result 摘要
ToolResult.source_system → Evidence.source
ToolResult.query_id  → Evidence.query（溯源）
ToolResult.time_range→ Evidence.evidence_t / freshness
ToolResult.evidence_ids → Evidence 关联（P7.4 去重键）
```

**关键**：
- Evidence 只记录**查询事实**，不记录 LLM inference（P7.4：LLM inference 绝不作为 Evidence）。
- `evidence_required=true` 的 Tool（P7.1）必须产出 Evidence。

## 5. Test Plan（P7.3）

### T1 状态归一化

- [ ] 空结果 → `no_data`
- [ ] backend 不可达 → `unavailable`
- [ ] 授权拒绝 → `permission_denied`
- [ ] 超时 → `timeout`
- [ ] backend 查询错误 → `failed`
- [ ] 部分 backend 成功 → `partial`
- [ ] 正常 → `success`

### T2 禁止降级（§94 红线）

- [ ] `permission_denied` 不降级为 `no_data`
- [ ] `no_data` 不降级为 `healthy`
- [ ] `unavailable` 不降级为 `healthy`
- [ ] backend 403 不降级为 `no_data`
- [ ] network error 不降级为 `no_data`

### T3 重试与超时

- [ ] `permission_denied`/`no_data` 不可重试
- [ ] `failed`/`timeout`/`unavailable` 可重试（受 retry 上限）
- [ ] 超时 → `timeout`（不无限等待）

### T4 Evidence 兼容

- [ ] `ToolResult.data` → Evidence.result 摘要正确
- [ ] `source_system`/`query_id`/`time_range` 正确映射到 Evidence
- [ ] `evidence_ids` 关联建立（P7.4 可查询）
- [ ] `evidence_required=true` Tool 必产 Evidence
- [ ] LLM inference 不进 Evidence

### T5 Schema 完整

- [ ] `output_schema` 校验 data 字段
- [ ] 缺 `source_system`/`query_id`/`time_range` → 校验失败
- [ ] `status` 非法值 → 拒绝

### T6 Context Traceability（评审建议 4）

- [ ] `ToolRequest.request_id` → `TrustedContext` → `ToolResult.request_id` → `Evidence` 全链路一致
- [ ] `request_id` 由 InternalQueryClient 生成（非 LLM 生成）
- [ ] `provenance.tool_id`/`trusted_context_id` 与调用一致
- [ ] `permission_denied` 携带 `denied_scope`（required_capability/denied_scope）
- [ ] `partial` 携带 `partial_reason`
- [ ] `source_system` 不允许 AI/LLM/Agent
