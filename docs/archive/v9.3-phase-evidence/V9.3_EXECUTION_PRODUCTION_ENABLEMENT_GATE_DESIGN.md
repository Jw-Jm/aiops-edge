本 Gate 设计真实生产执行的准入方案。**不含真实 K8s/OpenStack 连接、不含真实 credential 注入、不含生产变更动作。**
目标是定义"什么条件下才允许从安全基础设施进入真实生产执行"。

核心命题：

> Execution Infrastructure 已建立安全执行链。Production Enablement 回答：在什么环境/权限/审批/回滚保障下，才允许 Adapter 连接真实系统执行被批准的动作？

## PE.1 真实 K8s Adapter 安全评审（N2 纳入）

### 原则

生产 K8sAdapter **不继承 MockAdapter**（N2：避免测试逻辑污染生产），独立实现 `Adapter Interface v1`。

```text
Adapter Interface v1
   ├── MockAdapter（测试，仅内存）
   ├── K8sAdapter（生产，独立实现）
   └── OpenStackAdapter（生产，独立实现）
```

### K8sAdapter 安全要求

| 项 | 要求 |
|----|------|
| RBAC | 最小权限 role（仅 contract.allowed_actions 对应 verb） |
| namespace 隔离 | 仅 contract.allowed_resources 指定 namespace |
| 只读探测 | 执行前只读 get/list 校验资源存在 |
| dry-run | 支持 `--dry-run=client` 无副作用 |
| 连接 | 经 Broker short-lived credential（不持 kubeconfig 明文） |
| 版本漂移 | 执行前 verify_no_drift（EX.5） |

---

## PE.2 OpenStack Adapter 安全评审

### 原则

与 K8sAdapter 同构（Adapter Interface v1），独立实现。

### 要求

| 项 | 要求 |
|----|------|
| policy scope | project/region 限制（仅 contract 允许范围） |
| action 白名单 | 仅 contract.allowed_actions（如 server restart，禁 delete/evacuate） |
| 凭据 | 经 Broker short-lived（OpenStack token，随 expire 失效） |
| 幂等 | R4.1 idempotency_key 防重复操作 |
| before/after state | 执行前后 server 状态采集（回滚依据） |

## PE.3 Credential Broker 生产接入

### 生产 Broker 方案

```text
credential_ref
   ↓
生产 Credential Broker（Vault / K8s ServiceAccount 短期凭据）
   ↓
Short-lived Credential（TTL ≤ contract expire_time）
   ↓
Adapter
```

### Security Review 清单（评审建议）

| 项 | 要求 |
|----|------|
| TTL | ≤ contract expire_time（不超限） |
| scope | 不能超过 contract.allowed_resources/actions |
| audit | 必须记录申请/释放（R4.3 credential_issue_event） |
| revocation | contract revoke 后立即失效（Broker revoke） |
| 最小权限 | 非全 cluster admin（EX.2 延续） |

## PE.4 RBAC 最小权限验证

### 设计

每个生产 Adapter 绑定一个最小 RBAC role（按 contract 动态收缩）：

```text
Contract.allowed_actions → verb 映射:
  restart  → {get, list, patch(subresource: restart)}
  scale    → {get, list, patch(subresource: scale)}
  ...（白名单内才生成 verb）
```

### 验证矩阵

| contract.allowed_actions | 生成 RBAC verb | 拒绝的 verb |
|--------------------------|----------------|-------------|
| restart | get/list/patch-restart | delete/create/evacuate |
| scale | get/list/patch-scale | delete |
| （白名单外） | 无 | 全部拒绝 |

## PE.5 回滚演练方案

### 目的

在生产执行前，用 staging 环境验证回滚流程真实有效（非生产演练）。

### 流程

```text
staging 环境:
  1. 执行一个受限动作（contract A）→ 采集 before_state
  2. 制造失败/恶化
  3. 请求 rollback（rollback_contract_id，Human 批准）
  4. Adapter 回滚到 before_state
  5. 验证恢复 + 审计链完整
```

### 通过标准

- 回滚后状态 == before_state
- rollback 经 Human 批准（Agent 不能自动）
- 审计链（approved_by/requested_by/executed_by）完整

## PE.6 灰度执行方案

### 目的

真实执行渐进放量，降低风险。

### 阶段

```text
Stage 0: dry-run（无副作用，验证 contract/scope/credential）
Stage 1: 单资源（最小 namespace，1 个目标）
Stage 2: 受限范围（白名单内 namespace 子集）
Stage 3: 全量（仅 contract 明确授权范围）
```

### 闸门

- 每阶段通过后才能进入下一阶段
- 任一阶段 denied/failed → 停止，进入回滚（PE.5）
- 每阶段记录 before/after state + audit

## PE.7 Production Execution Approval 流程

### 设计

正式生产执行的完整审批链：

```text
PlanProposal(awaiting_approval)
   ↓ Human approval（Ed25519 signature，EX.1）
ExecutionContract(active, signed)
   ↓ Policy ALLOW（真实 SoT，EX.6）
   ↓ ExecutionPreview approved（防漂移，EX.5）
   ↓ Credential Broker（short-lived，EX.2）
   ↓ Adapter.execute（灰度，PE.6）
   ↓ success → executed | 失败 → rollback（PE.5，Human 批准）
```

### Break Glass / Emergency Revoke（N1 纳入）

```text
Break Glass:  紧急人工介入，绕过常规 approval（记录 + 事后审计）
Emergency Revoke: contract/credential 立即失效（revoke），阻断执行
```

## 威胁模型（N1 纳入）

| 威胁 | 缓解 |
|------|------|
| 恶意 Agent 越权执行 | contract 白名单 + Adapter 二次校验 + RBAC 最小权限 |
| 凭据泄漏 | Broker 唯一接触 + short-lived + 不落 Evidence |
| 执行对象漂移 | EX.5 verify_no_drift |
| 重复执行（timeout retry） | R4.1 idempotency |
| 权限期间变化（RBAC） | R4.2 permission snapshot |
| 无授权执行 | EX.1 signature + Approval 流程 |
| 回滚失败 | PE.5 演练 + before_state 保障 |

## Gate 判定（准入标准）

```text
Execution Production Enablement Gate = PASS 条件:

1. K8s/OpenStack Adapter 安全评审通过（独立实现，N2）
2. Credential Broker 生产接入方案通过（TTL/scope/audit/revocation）
3. RBAC 最小权限验证通过
4. 回滚演练方案通过（staging）
5. 灰度执行方案通过
6. Production Approval 流程 + Break Glass/Emergency Revoke 就绪
7. N1 威胁模型覆盖

通过后: Execution Production Execution = APPROVED（另立 Gate 批准）
未通过: 保持冻结
```
