## 5. Boundary Verification

- ❌ 无 UI / 无事件自动触发 / 无 Auto Run Creation
- P7.8：AI 调查仅人工显式触发；Alert/Event/Change 不自动创建 Run；Run 后无后台自动新建；无独立 Detection Engine / 告警自动 Agent 图
- System Principal 无执行权（三身份分离：User≠Service≠Execution；JWT(user) ≠ execution permission）

## 6. Known Tradeoff

- `run_auto_continue` 用 run_status 判定（running vs completed/cancelled/failed）；真实 Run 状态机接入属 P7.7/后续。
- `USER_EXPLICIT_SOURCES` 当前仅 user_explicit；真实"交给 AI 调查"按钮鉴权（realtime authorization）属后续阶段（本 MVP 验证边界逻辑）。
