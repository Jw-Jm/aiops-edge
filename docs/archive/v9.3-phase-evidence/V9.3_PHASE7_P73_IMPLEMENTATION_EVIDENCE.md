## 6. Known Tradeoff

- `_is_empty_payload` 用"所有字段为空值"判定 no_data；若某 backend 返回 `{"error":"X", "meta":{...}}` 且 error≠NO_DATA，会被判 success——但 P7.2 层已对非 200 归一化，此判定仅针对 200 响应，语义安全。
- `combine_partial` 用浅合并 body；精确 multi-source 合并留待 P7.9 Data Source Mapping 校准。
