## 1. P7.4 Contract

### 职责

- **统一证据对象**：保存、关联、追踪 ToolResult 产生的事实证据。
- **只记录不判断**：Evidence Hub 不做执行判断，不改变 VM/VLogs/MySQL SoT。
- **证据唯一性**：同一事实去重（provenance_fingerprint），不重复计分（§三十五）。

### 核心流程（P7.4，第 4170 行）

```text
ToolResult
   ↓ normalize
provenance key/hash
   ↓ dedup
Evidence 对象
   ↓ reliability
source_reliability
   ↓ immutable metadata
大型 payload → MinIO（MySQL 只存 ref/digest/summary/metadata）
```

**铁律**：**LLM inference 绝不作为 Evidence**（P7.4）。

### 边界

| 允许 | 禁止 |
|------|------|
| 保存查询事实（source/query/result/hash） | LLM inference 作为 Evidence |
| 关联（run_id/evidence_id） | 复制同一事实成多个"新证据"提分 |
| 去重（provenance_fingerprint） | 大型 raw logs/traces 塞 `ai_evidence` |
| 生命周期（created/validated/expired/archived） | 修改 immutable metadata |

## 2. Evidence Lifecycle

```text
Evidence
   ↓
created    // 查询产生，尚未校验
   ↓
validated  // 已核对来源/hash，可用于推理
   ↓
expired    // 超出时效，不再视为当前事实
   ↓
archived   // 归档保留（审计），不参与活跃推理
```

**关键语义**：**旧证据 ≠ 当前事实**。`expired`/`archived` 不得作为 live fact 依据。

## 3. Evidence Schema（§三十三 + v0.2 状态）

```text
Evidence {
  evidence_id           string
  run_id                string
  tenant_id             string   // canonical
  cluster_id            string   // canonical
  evidence_type         enum     // §三十四 13 种
  claim_type            enum     // fact|inference|knowledge|unknown
  source                enum     // VM|VLogs|query-api|MySQL|k8sgpt|knowledge（禁止 AI/LLM）
  source_reliability    float    // §三十六 可靠性
  resource_id           string
  namespace / service / pod / node
  trace_id              string
  observed_at           time
  time_range_start / time_range_end
  fact                  string   // 事实断言
  raw_ref               string   // 大型 payload → MinIO object ref
  raw_digest_sha256     string   // 结果指纹
  metadata              object   // 摘要（MySQL 保存）
  provenance_fingerprint string  // 去重键（§三十五）
  reliability           object   // {score, method, calculated_at}（评审建议 1）
  status                enum     // created|validated|expired|archived（v0.2）
  created_at            time
}
```

### reliability（评审建议 1）

```text
reliability: {
  score,           // 证据质量（§三十六 source_reliability）
  method,          // 计算方法
  calculated_at
}
```

**重要边界**：reliability 只能评价**证据质量**（如"VM 查询来自可信数据源"），
**不能评价结论正确性**（如"证明根因是数据库慢"——那属于 Reasoning Plane）。

### Evidence 类型（§三十四，13 种）

```text
metric_anomaly / log_pattern / log_error / trace_anomaly / k8s_state / k8s_event /
alert / change / knowledge_case / topology_relation / resource_state /
capacity_anomaly / hardware_event
```

### claim_type 规则（§三十四）

```text
fact      → 必须引用现场数据
inference → 必须引用 supporting evidence IDs
knowledge → 必须引用 document/source
unknown   → 必须记录缺失原因（reason 枚举，评审建议 3）
```

**claim_type=unknown reason 枚举（冻结）**：
```text
reason:
  - insufficient_data        // 数据不足
  - permission_denied        // 无权限
  - unavailable_source       // 数据源不可达
  - expired_evidence         // 证据过期
```
避免 `unknown` 变成垃圾桶。

**Hypothesis 是独立实体，不是 claim_type**（§三十四）。

## 4. Provenance & Dedup（§三十五）

### provenance_fingerprint 计算（最少基于）

```text
source
source_record_id or query_id
resource_id
observation/time range
raw digest (sha256)
```

### 去重规则

- 同一事实被多个 Agent 引用 → **同一 evidence_id**，不在 RCA 重复计分
- Agent 可引用同一 evidence_id，**不得复制成多个"新证据"提高置信度**（§三十五）
- 相同 `provenance_fingerprint` → 复用已有 Evidence，不新建

### Immutable

- Evidence 的 metadata/`provenance_fingerprint`/`raw_digest_sha256` **不可变**（P7.4 immutable metadata）
- 仅 `status` 可随时间迁移（created→validated→expired→archived）

## 5. Storage 分层

### MySQL（`ai_evidence`，索引层）

只保存：

```text
raw_ref / raw_digest_sha256 / fact / summary / metadata / provenance_fingerprint
```

### MinIO（大对象层）

```text
大型 raw payload（logs/traces/快照）→ MinIO object
MySQL 保存 raw_ref（object ref）+ digest
```

**禁止**：把大型 raw logs/traces 整体塞 `ai_evidence`（§三十三）。

## 6. Test Plan（P7.4）

### T1 归一化与落库

- [ ] `ToolResult → Evidence` normalize 正确（data/source/query/time_range 映射）
- [ ] 大型 payload → MinIO，MySQL 只存 ref/digest/summary
- [ ] evidence_type/claim_type 赋值正确

### T2 去重（§三十五）

- [ ] 相同 `provenance_fingerprint` → 复用同一 evidence_id，不新建
- [ ] 同一事实多 Agent 引用 → 单 Evidence，不重复计分
- [ ] 复制成"新证据"提分 → 被拒绝/去重

### T3 生命周期

- [ ] created → validated 迁移正确
- [ ] 超时 → expired（不再作为 live fact）
- [ ] expired → archived（审计保留）
- [ ] 旧证据不作为当前事实依据

### T4 不可变 + LLM 红线

- [ ] metadata/provenance_fingerprint/digest 不可变
- [ ] 仅 status 可迁移
- [ ] **LLM inference 绝不作为 Evidence**（拒绝写入）
- [ ] claim_type=inference 必须引用 supporting evidence IDs

### T5 关联与追溯

- [ ] `run_id`/`evidence_id` 关联正确（P7.6 Planner 可引用）
- [ ] `source` 不允许 AI/LLM/Agent
- [ ] claim_type=unknown 记录缺失原因（reason 枚举）

### T6 Evidence Freshness Isolation（评审建议 2）

- [ ] `expired` evidence **不能**作为 current fact 提供给 Planner/Agent
- [ ] `archived` evidence 仅审计/回顾可用，不参与活跃推理
- [ ] Planner 引用 `expired`/`archived` → 被拒绝或标记为 stale
- [ ] `freshness` 窗口正确驱动 status 迁移（validated→expired）
- [ ] **旧证据 ≠ 当前状态**（不 overwrite current state）
