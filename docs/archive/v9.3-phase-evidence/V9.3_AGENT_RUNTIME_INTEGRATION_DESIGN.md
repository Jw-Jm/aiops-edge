## 1. Integration Contract

### 职责

- 把 Agent 的 `tool_executor`（内存 mock）替换为 **InternalQueryClient（P7.2）→ query-api**。
- 完整 Agent 闭环：Planner DAG → Agent → query-api → ToolResult → Evidence → 回填 Planner。
- 纳入 N3（Agent Insight 输出协议冻结）、N1（真实 Tool Executor）、N2（Resource Graph 采集）。

### 边界

| 允许 | 禁止 |
|------|------|
| Agent 经 InternalQueryClient → /internal/v1/query/* | direct DB/CH/VM/VLogs/K8s |
| 每次调用签 TrustedRequestContext V2 | Agent 绕过 query-api authorization |
| Agent 输出标准化 AgentInsight（N3） | 各 Agent 自定义输出协议 |
| Resource Graph 从 query-api 采集 | Agent 直接连集群/informer |

### 非目标（本设计不做）

- ❌ 不实现真实 query-api 接入（仅设计；接入实现另行授权）
- ❌ 不接真实 K8s/OpenStack/CMDB informer

## ARI.1 Tool Registry → 真实 query-api 集成

### 当前（Phase 8）

```text
Agent.run → AgentRuntimeFramework.execute_step → tool_executor(内存 mock) → ToolResult
```

### 目标（ARI.1）

```text
Agent.run → AgentRuntimeFramework.execute_step → InternalQueryClient(P7.2)
   → TrustedRequestContext V2 → query-api /internal/v1/query/*
   → normalize ToolResult → Evidence Hub
```

### 设计

- `tool_executor` 默认替换为 `InternalQueryClient.query()`（P7.2）。
- 每次调用按 `tenant/cluster/capability` 签发 TrustedRequestContext（P7.2 TrustedContextIssuer）。
- 权限传递：Agent 的 capability = 所绑定 Tool 的 capability（P7.1），不扩大。
- timeout/retry：受 Tool.timeout_class/timeout/retry（P7.1）约束。
- audit：request_id 全链路（Agent → query-api → Evidence）。

### 约束

- **唯一事实路径**：Agent 只经 query-api（禁 direct DB/K8s，P7.2 延续）。
- capability 精确（Agent 不自选 capability）。
- Tool 未注册/非 active → 拒绝（P7.1）。

## ARI.2 Agent Evidence 生命周期

### 设计

Agent 产出 ToolResult → Evidence 的完整生命周期（P7.4）：

```text
ToolResult(success/partial)
   ↓ save_from_tool_result
Evidence(created)
   ↓ validate
Evidence(validated)   ← 可作为 Agent 推理依据
   ↓ freshness 窗口
Evidence(expired)     ← 不再作为 live fact
   ↓
Evidence(archived)    ← 审计保留
```

### 约束

- **LLM inference 绝不进入 Evidence**（P7.4 铁律）。
- Agent Insight（分析）≠ Evidence（事实）：Insight 是 Agent 输出，Evidence 是查询事实。
- freshness isolation：expired/archived 不作为 Agent 推理的 live fact。

## ARI.3 Resource Graph 数据采集设计（N2 纳入）

### 设计

Resource Graph V1（P8.9）从 query-api 采集资源构建 typed graph：

```text
query-api /internal/v1/query/topology → nodes/edges
   ↓ 权限过滤（tenant/cluster/capability）
ResourceGraph V1（typed node/edge）
```

### 采集源（后续接入，当前仅设计）

```text
K8s informer（经 query-api Kubernetes boundary）
OpenStack inventory
CMDB
network topology
```

### 约束

- 采集只经 query-api（Agent 不直连 informer/CMDB）。
- tenant/cluster 隔离保持（P8.9 延续）；禁跨 cluster edge。
- 当前 V1 不引入自动拓扑发现/自动修复（评审 N2 认可）。

## ARI.4 Agent Insight 与 Planner DAG 集成

### 设计

Agent 输出回填 Planner DAG（P7.6）：

```text
Planner DAG → 单个 PlanStep → Agent.run
   ↓ AgentInsight（N3 协议）
Planner 收集 evidence_refs / missing_slots
   ↓ 依赖满足 → 下一 step
   ↓ MissingEvidence → follow-up slot（budget 约束）
```

### 约束

- Agent 不决定调查顺序（Planner DAG 唯一控制）。
- MissingEvidence 受 budget 约束（P7.6），不无限追加。
- Agent 输出只作证据输入，不直接产出最终根因。

---

## ARI.5 Agent Runtime 与 Execution Boundary 隔离验证

### 设计

确认 Agent 与 Execution（Phase 11 前置）完全隔离：

```text
Agent（ARI）：Evidence collection + Insight generation
   ≠
Execution（Trusted Execution Foundation）：Approved Action Execution
```

### 隔离断言

- Agent 无 execute/self_execute（Phase 8 已断言）。
- Agent 不触碰 ExecutionContract / Adapter / Credential Broker。
- Agent 输出（Evidence/Insight）不触发任何执行动作。
- 验证：Agent 运行不产生执行副作用。

## N3 纳入：Agent Insight 输出协议冻结

```text
AgentInsight {
  agent_type        string    // observability|log|trace|kubernetes|change|knowledge|infrastructure
  evidence_refs     []string  // 该 Agent 产出的 Evidence ids（P7.4）
  insights          []object  // 领域分析结果（不归因）
  confidence        float     // 置信度（不评价结论正确性）
  missing_slots     []object  // MissingEvidence（tool_id/capability/reason）
}
```

**约束**：所有 Agent 统一输出 `AgentInsight`（禁止各 Agent 自定义输出协议）。

## 统一 Agent 集成路径（ARI 确立）

```text
Planner DAG
   ↓ PlanStep
Agent.run
   ↓ InternalQueryClient → TrustedRequestContext V2 → query-api（ARI.1）
   ↓ normalize ToolResult → Evidence Hub（ARI.2）
   ↓ AgentInsight（N3 协议）→ 回填 Planner（ARI.4）
   ↓ Resource Graph 经 query-api 采集（ARI.3）
   ↓ 隔离：不触发执行（ARI.5）
```

## 安全分层

```text
分析（Phase 8）: 七类 Agent + Resource Graph
集成（ARI）:     Agent → query-api 真实事实路径
证据（P7.4）:    Evidence 生命周期 + freshness
隔离（ARI.5）:    Agent ≠ Execution（无执行副作用）
```

## 红线保持（F1-F5 + ARI）

```text
F1 LLM 非权威：Agent 不自选 capability；Agent Insight 不生成权限
F2 三+一身份：Agent 经 TrustedRequestContext（tenant/cluster/capability）
F3 Evidence 边界：LLM inference 不进入 Evidence；Insight ≠ Evidence
F4 Planner 边界：Agent 不决定调查顺序（Planner DAG 唯一）
F5 End State：本阶段不触发真实执行
新增：Agent 只经 query-api（唯一事实路径）；Agent ≠ Execution
```
