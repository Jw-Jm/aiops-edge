- **T1 意图解析**：显式 cluster/service/time → 结构化 Intent；action_mode/target_type 枚举校验；缺 time_range 用默认 PASS

- **T5 State Machine**：IntentCreated→EvidenceCollected→PlanGenerated→AwaitingApproval；Phase7 不进入 Approved/Executed；非法跳迁移拒绝 PASS
- **T6 Capability Non-Creation**：delete 请求 action_mode=plan_only + capability 来自 Registry；LLM 注入 k8s.delete → 拒绝 PASS
