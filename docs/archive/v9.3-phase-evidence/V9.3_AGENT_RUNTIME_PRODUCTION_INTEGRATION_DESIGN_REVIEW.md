## 三、分项评审结论

### PI.1 Real query-api Production Integration Design —— PASS

目标链路：

```text
Agent Runtime → InternalQueryClient → (mTLS) → query-api /internal/v1/query/*
```

认可点：
1. **query-api 仍是唯一事实入口**：`Agent → InternalQueryClient → query-api → Evidence`，未退化 `Agent → DB/K8s`。
2. **Authorization 模型正确**：Context V3 验证 `signature valid && capability allowed && tenant permitted`，否则 DENY。符合 V9.3："AI 可以请求事实，但不能决定权限"。

### PI.2 TrustedRequestContext V3 —— PASS

V2：`tenant cluster capability request_id nonce`
V3 增加：`issuer timestamp expiry signature key_id`

| 风险       | 机制      |
| ---------- | --------- |
| 请求伪造     | signature |
| 请求重放     | nonce     |
| 过期请求     | expiry    |
| 密钥轮换     | key_id    |
| 租户越界     | tenant    |

安全价值完整。

### PI.3 ResourceGraph Production Data Integration —— PASS

生产数据来源：Kubernetes / OpenStack Inventory / CMDB / Network Topology，统一：

```text
Data Source → query-api boundary → ResourceGraphProvider → Resource Graph
```

**关键边界正确**：
- 禁止 `Agent → Kubernetes informer`
- 禁止 `ResourceGraph → CMDB`

生命周期设计认可：Snapshot（`graph_snapshot_id/timestamp/version`）、Incremental Update（add/remove/change edge）、Stale Detection（`last_seen/expire_time/status`）——生产 RCA 必需能力。

### PI.4 Agent Runtime Production Observability —— PASS

- **Metrics**：agent_run_total / agent_run_duration / agent_failure_total；tool_query_latency / tool_timeout_total / tool_denied_total；evidence_created / evidence_expired / missing_slot_total
- **Trace**：Planner DAG → Agent.run → InternalQueryClient → query-api → Evidence

符合云原生可观测要求。

### PI.5 Execution Production Gate Isolation —— PASS

强制隔离：Agent 禁止接触 ExecutionContract / Adapter / Credential Broker / kubeconfig / secret。

自动验证：CI `grep execute / credential / kubeconfig / adapter`，Agent package 必须 **0 match**。

把隔离从"设计约束"升级为"持续验证约束"——非常关键。

### N3 AgentInsight Schema v1.1 —— PASS

v1：`agent_type / evidence_refs / insights / evidence_confidence / missing_slots`
v1.1 新增：`schema_version / trace_id`

用途：Schema 演进 + 全链路追踪，合理。
