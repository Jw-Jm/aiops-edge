## 1. P7.7 Contract

### 职责

- **围绕现有 Run 维护调查状态**（P7.7）：steps 状态、ToolResult refs、Evidence refs、
  missing evidence、budget consumed/remaining。
- **结构化**：不靠 prompt 历史恢复状态（P7.7 明确禁止）。

### 边界

| 允许 | 禁止 |
|------|------|
| 维护 pending/running/completed steps | 仅靠 prompt 历史恢复状态 |
| ToolResult / Evidence refs | 新增 Incident/Detection 状态机 |
| missing evidence | 状态影响外部资源 |
| budget consumed/remaining | 包含执行指令 |

## 2. State Schema

```text
InvestigationState {
  run_id               string
  intent_id            string
  plan_id              string
  phase                enum     // IntentCreated|EvidenceCollected|PlanGenerated|AwaitingApproval
  steps                [StepState]
  tool_result_refs     [ref]    // ToolResult 引用
  evidence_refs        [ref]    // Evidence 引用（P7.4）
  missing_evidence     [MissingEvidence]
  budget               { consumed_steps, consumed_tools, consumed_latency, remaining }
  findings             [string] // 调查发现（不含执行指令）
  hypotheses           [Hypothesis]  // 独立实体（§三十四），引用 supporting evidence
  confidence           float
  status               enum     // IntentCreated|EvidenceCollected|PlanGenerated|AwaitingApproval
}

StepState {
  step_id
  status        // pending|running|completed|skipped|failed
  result_ref    // ToolResult / Evidence ref
  started_at, finished_at
}
```

**约束**：
- `findings`/`hypotheses` 只记录调查结果，**不含执行指令**
- 状态更新不影响外部资源
- **禁止**再新增 Incident/Detection 状态机（P7.7）

---

## 3. State Machine（与 P7.5 一致）

```text
IntentCreated
   ↓
EvidenceCollected
   ↓
PlanGenerated
   ↓
AwaitingApproval      ← Phase7 边界
   ↓
Approved              ← 后续阶段
   ↓
Executed              ← 后续阶段
```

**Phase7**：只推进到 `AwaitingApproval`。
