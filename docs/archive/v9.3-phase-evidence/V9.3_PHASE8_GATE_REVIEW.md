# Schema v1 — 冻结清单

## 1. ExecutionContract Schema v1

```text
ExecutionContract {
  contract_id        string            // 唯一
  plan_id / intent_id / run_id         // 关联 P7.6/P7.5/P7.7
  requested_by       string            // 谁发起（Agent/User）
  approved_by        string            // 谁批准（Human）
  approved_at        time
  executed_by        string            // 执行身份 ref（P8.2 ExecutionIdentity）
  allowed_tools      []string          // 已注册 Tool 白名单
  allowed_resources  []string          // 允许作用资源
  allowed_actions    []string          // 动作白名单（缺省拒绝，非黑名单）
  max_scope          enum              // cluster|namespace|resource
  expire_time        time              // 一次性短时效
  rollback_policy    object            // {rollback_action, rollback_timeout, requires_approval}
  contract_hash      string            // SHA256(contract_id+actions+resources+expire_time)
  signature          string            // 审批签名（当前确定性哈希；R1→Ed25519）
  created_version    string            // schema 版本
  status             enum              // draft|approved|active|executing|executed|expired|revoked
}
```

**状态机（单向，不可逆回）：**
```text
draft → approved → active → executing → (expired|revoked|executed)
```

**不变式：**
- 一次性：executed 不可复用；expired 不可续；revoked 不可逆
- 白名单：allowed_actions 缺省拒绝
- scope 不扩大：max_scope 来自当前 Run
- contract_hash 不可变：执行时校验防篡改
- execution_lock：active → acquire_lock → executing；同 contract 二次 acquire_lock 拒绝（防并发）

## 2. ExecutionIdentity Schema v1

```text
ExecutionIdentity {
  identity_id        string            // UUID（executed_by 引用）
  run_id / contract_id                  // 关联 P7.7 / P8.1
  executed_by        string            // 执行身份 principal
  identity_type      enum              // user|service|execution
  principal_id       string            // 底层 identity ref
  credential_ref     string            // 凭据委托引用（不存 Secret）
  scope              string            // 绑定 scope（不自动扩大）
  issued_at / expire_time              // 随 contract 一次性过期
  status             enum              // issued|active|expired|revoked
}
```

**审计链（强制）：**
```text
approved_by（Human）→ requested_by（Agent）→ executed_by（Execution Identity）→ contract_id
每次执行必须能追溯完整三环，缺任一环拒绝。
```

**不变式：**
- executed_by UUID 化（独立实体，独立生命周期）
- Agent 不能自选 executed_by（scope 超 contract.allowed_resources → 拒绝）
- credential_ref 只引用委托凭据，不存 Secret
- 身份声明 ≠ 执行权限（F2 延续）

## 3. Adapter Interface v1

```text
interface ExecutionAdapter v1 {
  execute(request: AdapterRequest) -> AdapterResult
  dry_run(request: AdapterRequest) -> AdapterResult
  verify_contract_scope(request, contract) -> bool
}
```

```text
AdapterRequest {
  contract_id        string
  credential_ref     string            // 委托凭据引用
  target             object            // {namespace, resource_type, resource_id}
  action             string
  params             object
  dry_run            bool
}

AdapterResult {
  status             enum              // success|failed|denied|dry_run
  output             object
  rollback_ref       string
  executed_at        time
  adapter_id         string
  target_snapshot    object
  before_state       object            // 执行前状态（如 replicas=3）
  after_state        object            // 执行后状态（如 replicas=5）
  execution_trace_id string
}
```

**不变式：**
- 所有真实 Adapter（K8s/OpenStack/VM）必须实现 v1 接口（禁止各自扩展）
- fail-closed：contract 非 active / action 白名单外 / target 范围外 / 无 credential → denied
- dry_run 无副作用
- before_state/after_state/target_snapshot 必须记录（可靠 RCA）
- Adapter 不持有/保存 credential

## 4. Policy Context Contract v1

```text
PolicyRule {
  policy_id        string
  policy_type      enum   // time_window|resource_scope|action_scope|rate_limit|impact_limit
  allowed_values   []string
  denied_values    []string
  limit            int
  scope            string
}

PolicyDecision {
  decision         enum   // ALLOW|DENY
  reason           string
  policy_id        string
  checked_at       time
}
```

**Policy Context 来源（冻结，评审最大风险点）：**
```text
权威来源（允许）:
  current_time        // 当前时间（时间窗口）
  cluster_state       // 集群真实状态
  execution_history   // 历史执行（次数/影响累积）
  authorization_sot   // MySQL Authorization SoT

禁止（PolicyContextInvalid → 拒绝）:
  ❌ llm_output
  ❌ agent_suggestion
  ❌ frontend_param
```

**不变式：**
- 5 类检查全实现（时间/资源/动作/次数/影响）
- DENY 不降级为 ALLOW；DENY 理由可审计（policy_id + reason）
- 策略绑定 contract + Run scope，不自动扩大
- **LLM/Agent/Frontend 绝不能作为 Policy 来源（F1 延续）**

## 5. ExecutionPreview Contract v1

```text
ExecutionPreview {
  preview_id         string
  contract_id        string
  target             object            // {namespace, resource_type, resource_id}
  impact             string
  risk               enum              // low|medium|high
  actions            []string
  environment_snapshot object          // 执行前环境状态快照
  resource_version   string            // 目标资源版本
  expected_change    object            // 预期变更
  rollback_plan      object            // 回滚计划
  status             enum              // pending|approved|rejected
}
```

**不变式：**
- 生成 preview 无副作用（纯只读模拟）
- 缺环境状态快照（environment_snapshot/expected_change/resource_version）→ 拒绝 approved
- 只有 approved 的 preview 才允许 Adapter 真实执行
- Rollback 责任边界：Agent 建议 / Human 批准 / Policy 检查 / Adapter 执行；禁 Agent 自动 rollback
