## 1. P7.6 Contract

### 职责

- **唯一调查 DAG 控制器**（P7.6）：接收 Intent（P7.5），产出 **Plan Proposal**。
- **只产出提案**：输出 `ToolResult[]/Evidence[]/MissingEvidence[]`，**不得直接输出最终 Root Cause**（§四十二）。
- **预算控制**：严格执行冻结预算（max_steps/max_tools/max_latency）+ timeout/retry（P7.6）。

### 边界

| 允许 | 禁止 |
|------|------|
| 生成调查 DAG（steps + dependency） | Planner → Executor 直连 |
| 预算计数/超限终止（BUDGET_EXCEEDED） | 输出最终根因 |
| MissingEvidence follow-up slots | 无限探索 |
| parallel-safe branches | 第二套 Agent 主图 |
| 产出 Plan Proposal（经人工 approval） | 跳过 approval 执行 |

## 2. Plan Proposal Contract

```text
PlanProposal {
  plan_id          string
  intent_id        string
  status           enum     // pending|running|completed|awaiting_approval|budget_exceeded|failed
  risk_level       enum     // R0..R4
  requires_human_approval bool // 强制 true（v0.2 规划）
  steps            [PlanStep]
  budget           Budget
  result           { tool_results: ToolResult[], evidence: Evidence[], missing_evidence: MissingEvidence[] }
  created_at, updated_at
}

PlanStep {
  step_id
  tool_id           // 已注册 Tool（P7.1）
  params
  depends_on        [step_id]   // step dependency
  status            // pending|running|completed|skipped|failed
  result_ref        // ToolResult / Evidence ref
}

Budget {
  max_steps
  max_tools
  max_latency
  consumed_steps
  consumed_tools
  consumed_latency
}
```

**硬预算**：`max_steps/max_tools/max_latency` 冻结，超限 → `budget_exceeded`，终止并报告，不强行收敛（§四十一）。

---

## 3. DAG Model

```text
steps + depends_on → DAG
  - step dependency（a 依赖 b 的 ToolResult）
  - parallel-safe branches（互不依赖的 step 可并行）
  - MissingEvidence follow-up slots（证据不足时补查 slot）
```

**约束**：
- 依赖满足才执行 step
- parallel 分支共享 budget 计数（总消耗不超预算）
- MissingEvidence 补查占用 budget，不无限追加

---

## 4. Approval Boundary

```text
Planner → Plan Proposal（requires_human_approval=true）
   ↓ user approval
RunInvocation → 执行（后续阶段）
```

**Phase7 停止点**：`awaiting_approval`。**禁止 Planner→Executor 隐式直连**（v0.2 规划 `requires_human_approval` 强制）。

---

## 5. MissingEvidence 处理

- 证据不足 → 生成 `MissingEvidence` slot（tool_id/capability/reason）
- 不强行归因；Planner 输出 `unknown/missing_evidence`
- follow-up slot 受 budget 约束，超预算 → `budget_exceeded`
