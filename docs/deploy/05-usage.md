# 05 使用指南

> 前端功能模块使用说明。覆盖登录、各功能页面用法、AI 诊断与审批流程。
> 面向平台使用者（运维/开发/管理员）。

---

## 1. 登录

- 访问前端入口：本机 `http://localhost:30253/`，生产 `http://<your-host>:30253/`
- 首次使用：注册/登录（后端内置认证，JWT 会话 24h）
- 角色：`admin`（管理员，可配规则/审批/用户）、普通用户（查看/诊断）

---

## 2. 平台总览

**路径 `/`** — 平台总览
- 全局健康仪表盘：服务数、告警数、错误率、延迟、拓扑概览
- 一眼掌握集群/服务运行状态

---

## 3. 可观测性

| 页面 | 路径 | 用途 |
|------|------|------|
| **服务列表** | `/services` | 所有服务的 RED 指标（请求/错误/延迟），点击进详情 |
| **服务详情** | `/services/:name` | 单服务指标趋势、依赖、拓扑、日志、trace |
| **服务拓扑** | `/topology` | 服务间调用拓扑图（依赖关系） |
| **拓扑目录** | `/topology/catalog` | 拓扑节点/边清单 |
| **链路追踪** | `/traces` | 按服务/耗时/状态查询 trace，点击进 trace 详情 |
| **Trace 详情** | `/traces/:traceId` | 单次调用链路瀑布图、span 明细 |
| **日志查询** | `/logs` | 按服务/关键词/时间查日志，支持聚合 |
| **监控面板** | `/monitor` | 自定义监控图表，**支持拖拽/缩放布局**（react-grid-layout） |
| **容量预测** | `/capacity` | 按指标（CPU/内存/磁盘/网络）预测趋势 + **ETT（预计触达阈值时间）** |
| **DeepFlow** | `/deepflow` | 深度网络观测（eBPF 数据），跳转 DeepFlow Grafana |

## 4. AI 智能运维

| 页面 | 路径 | 用途 |
|------|------|------|
| **AI 诊断** | `/aichat` | 用自然语言发起诊断（如"分析订单服务错误率升高"），流式返回分析/计划/脚本/结论 |
| **技能目录** | `/skills` | 可用的 AI 技能（诊断/RCA/巡检/问数等） |
| **AI 助理** | `/agents` | 多 Agent 协作（主 Agent + 子 Agent + 审阅 Agent） |
| **工作流** | `/workflows` | 可视化流程编排（DAG），可编辑/运行 |
| **SQL 查询** | `/nl2sql` | 用自然语言生成 ClickHouse SQL 并执行（受限表白名单） |
| **MCP 工具** | `/mcp` | MCP 工具接入与调用 |

### 4.1 AI 诊断审批流程
- AI 诊断生成的**写操作**（如 `kubectl scale`、`restart`）不会自动执行
- 在 **审批中心** 确认后才会执行（`human_approved` 门控）
- **只读命令**（`kubectl get/logs/top`）自动执行
- 安全：命令受 ShellPolicy 白名单约束，危险命令（rm -rf/sudo 等）被拦截

## 5. 告警与 SLO

| 页面 | 路径 | 用途 |
|------|------|------|
| **告警中心** | `/alerts` | 告警规则管理 + 告警事件列表；支持创建阈值/突变/异常/预测/烧毁率规则 |
| **SLO 管理** | `/slo` | 定义服务 SLO 目标，计算烧毁率 |
| **审批中心** | `/approvals` | AI/恢复操作的审批流（admin 审批） |
| **审计日志** | `/audit` | 全量操作审计（谁在何时做了什么） |

### 5.1 告警规则类型
| 类型 | 说明 |
|------|------|
| `threshold` | 阈值告警（错误率/延迟等） |
| `mutation` | 突变检测 |
| `anomaly` | 异常检测（需 admin） |
| `forecast` | 预测告警（需 admin） |
| `burn_rate` | 烧毁率告警（基于 SLO） |
| `metric_raw` | 原始 PromQL 告警（需 admin，防注入） |

### 9.1 系统设置要点

- **DeepFlow 配置**：DeepFlow Server / Grafana 地址（`VITE_*` 已注入时自动填）
- **恢复白名单**：告警自动恢复允许的命令列表

## 10. 常见使用流程

### 10.1 排查一次故障
1. **总览** `/` 看全局异常
2. **服务详情** `/services/:name` 看指标趋势
3. **日志查询** `/logs` 看错误日志
4. **链路追踪** `/traces` 定位慢调用/失败链路
5. **AI 诊断** `/aichat` 让 AI 分析根因并生成修复计划
6. **审批中心** `/approvals` 确认写操作执行

### 10.2 配置一条告警
1. **SLO 管理** `/slo` 定义目标
2. **告警中心** `/alerts` 创建规则（选类型/服务/阈值）
3. 触发后事件落 ClickHouse，可在 `/alerts` 查看并触发 AI 诊断
