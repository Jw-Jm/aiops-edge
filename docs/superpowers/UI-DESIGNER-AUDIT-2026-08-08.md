## 二、全局设计问题（跨页面）

### 🔴 D-01: 空白页面 = 设计灾难

**涉及页面：** 拓扑目录 `/topology-catalog`、AI 诊断 `/ai-diagnosis`、SQL 查询 `/sql`

**设计师判词：** 这是整个平台最大的设计缺陷。空白页面不是"未完成功能"的借口——它是对用户信任的破坏。用户看到空白的第一反应是"这东西坏了"。

**修复方案（按优先级）：**
1. **最低限度** — 显示 AntD `<Empty>` 组件 + 描述文案 + 引导按钮
2. **推荐方案** — Skeleton 加载态 → Empty 空态（含插画 + 文案 + CTA）
3. **最佳实践** — Onboarding 引导（首次进入时展示功能介绍 + "开始使用"按钮）

```
// 空态组件规范（建议统一）
<Empty
  image={emptyIllustration}        // 定制插画
  description="暂无数据"
  extra={<Button type="primary">新建</Button>}
/>
```

---

### 🟡 D-02: 页面标题区域缺乏呼吸感

**涉及页面：** 几乎全部页面

**观察：** 所有页面的标题栏都是 `h2 标题` 直接贴在内容区顶部，没有 padding-bottom 或分隔线。标题与下方内容之间的垂直间距不足（约 12-16px），导致视觉上"挤"。

**建议：**
```css
.page-header {
  margin-bottom: 24px;           /* 从 ~16px 提升到 24px */
  padding-bottom: 16px;          /* 加底部分隔 */
  border-bottom: 1px solid rgba(255,255,255,0.06); /* 极淡分割线 */
}
```

---

### 🟡 D-03: 侧边栏与主内容区对比度过低

**观察：** 侧边栏背景 `#111827` vs 主内容区背景 `#09090b`，亮度差仅约 3%。在低分辨率或非 Retina 屏上，两者几乎融为一体。

**当前值：**
- Sidebar bg: `#111827` (zinc-900)
- Main bg: `#09090b` (接近 black)
- 对比比: ~1.15:1（远低于 WCAG 任何级别）

**建议：** 将侧边栏提亮至 `#1a1f2e` 或加右侧 1px 分割线 `rgba(255,255,255,0.06)`。

---

### 🟢 D-04: 缺少全局 Loading 与 Skeleton

**观察：** 页面切换时无过渡动画或骨架屏。数据加载期间要么显示旧数据，要么突然闪现新内容。

**建议：** 为每个页面级路由添加 `<Spin>` 或 `<Skeleton active />` 包裹。

## 五、字体排版审计

### 当前字体栈


### 字号层级

| 层级 | 大约字号 | 用途 | 评价 |
|------|----------|------|------|

| 编号 | 问题 | 建议 |
