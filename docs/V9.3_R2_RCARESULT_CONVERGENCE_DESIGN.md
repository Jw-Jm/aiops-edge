## 1. 目标与 v0.3 架构

把 RCA 产出收敛到**唯一公开/持久化/wire 结果 `contracts.RcaResult`**，消除同名平行模型（审计 P1-6），并确保投影**无损且可复算**。

```
HypothesisEvaluation                              # 内部计算单元（非 wire）
  hypothesis
  score_breakdown
  support_relations
  contradictions
  missing_evidence

RcaComputation                                     # 内部计算轨迹（非 wire，禁止外传）
  snapshot
  evaluations: hypothesis_id → HypothesisEvaluation
  ranking
  conclusion_state                                 # confirmed/supported/rejected/unknown

        ↓ 单向投影（无损、可复算，须满足 §4 不变式）

contracts.RcaResult                                # 唯一公开/持久化/wire 结果
```

- `RcaEngine.evaluate(...) → RcaComputation`（内部，可测）
- `RcaEngine.run(...) → contracts.RcaResult`（唯一公开结果，直接返回权威合同）
- **不再定义 `class RcaResult`（rca_engine.py 或任何业务模块）**。内部计算轨迹改名为 `RcaComputation`。

**边界**：`investigation_state.Hypothesis` 收敛属独立子任务（§9）。不接真实系统、不改 Evidence→RootCause 推导逻辑、不动其他 Phase。

## 2. 权威子合同演进（决策：V2 增量演进，新增字段带默认，不破坏既有 wire）

评审指出当前权威子合同**缺少关联字段**导致有损映射。按 R2 版本策略（记忆 70487111：V2 只加不改，新增字段带默认），**在 contracts.py 增量新增字段（带默认值）**，不改既有字段/序列化值：

```python
class HypothesisScore(ContractModel):
    """评分分量（可复现，禁 LLM 给 confidence 数字）。"""
    llm_prior: float = Field(ge=0, le=1)
    evidence_support: float = Field(ge=0, le=1)
    source_reliability: float = Field(ge=0, le=1)
    temporal: float = Field(ge=0, le=1)
    contradiction_penalty: float = Field(le=0)   # 注意：必须 ≤0（负值）
    missing_penalty: float = Field(le=0)        # 注意：必须 ≤0（负值）
    final_score: float = Field(ge=0, le=1)
    hypothesis_id: UUID = None  # 新增：关联 hypothesis（评审 §子合同）


class Contradiction(ContractModel):
    kind: str
    severity: str  # critical / normal
    detail: str = ""
    resolved: bool = False
    hypothesis_id: UUID = None   # 新增
    evidence_id: UUID = None     # 新增


class MissingEvidence(ContractModel):
    kind: str  # critical / optional
    reason: str
    description: str = ""
    hypothesis_id: UUID = None    # 新增
    required_type: str = ""       # 新增：承载原始 required_type（不再塞进 description）
    followup_slot: str = None     # 新增


class RcaResult(ContractModel):
    # ...（既有字段不变）...
    status: str = "completed"  # completed / unknown
    conclusion_state: str = "unknown"  # 新增：confirmed/supported/rejected/unknown（权威状态）
    # ... root_cause/confidence/root_cause_refs/hypothesis_scores/contradictions/missing_evidence ...

    @model_validator(mode="after")
    def unknown_safe(self): ...  # 保留

    @model_validator(mode="after")
    def state_matrix(self): ...  # 新增：§5 状态矩阵一致性校验
```

> **规则**：新增字段一律带默认值（None/""/unknown），不改变既有序列化值，三端向后兼容。`required_type` 不再编码进 `description`（评审 §有损映射）。

## 3. RcaComputation 内部模型（非 wire）

```python
@dataclass
class HypothesisEvaluation:
    hypothesis: contracts.Hypothesis
    score_breakdown: ScoreBreakdown
    support_relations: list  # SupportMatcher relations_for(hypothesis_id)
    contradictions: list     # ContradictionChecker.Contradiction
    missing_evidence: list   # MissingEvidenceChecker.MissingEvidence
    support_matcher: SupportMatcher  # 供投影阶段使用（评审 §sm 错误索引）


@dataclass
class RcaComputation:
    snapshot: RcaInputSnapshot
    evaluations: dict  # hypothesis_id(UUID) → HypothesisEvaluation
    ranking: RootCauseRanking
    conclusion_state: str  # confirmed/supported/rejected/unknown
    timeline: Timeline
```

- `evaluate()` 构造完整 `evaluations`（按 hypothesis_id 索引），不再依赖循环外泄漏的 `sm`。
- `RcaComputation` **禁止外传**（非 wire），仅供内部测试与投影。

## 4. 单向投影（RcaComputation → contracts.RcaResult）—— 关键修复

### 4.1 penalty 负值映射（评审 §Penalty 正负号）
```python
def _penalty_sum(breakdown: ScoreBreakdown, types: set[str]) -> float:
    """注意：合同要求 penalty ≤ 0（Field(le=0)），而 Penalty.value 是正数 → 必须取负。"""
    return -round(sum(p.value for p in breakdown.penalties if p.type in types), 4)
```
> 非零 penalty 黄金测试：构造含 critical_contradiction 的场景，断言 `contradiction_penalty < 0` 且 `final_score == base + penalties`（可复算）。

### 4.2 evaluations 索引 + RootCauseRef（评审 §sm 错误索引）
```python
selected = comp.evaluations[ranking.root_cause.hypothesis_id]  # 显式索引，杜绝循环外 sm
root_cause_refs = []
if ranking.root_cause is not None:
    root_cause_refs.append(contracts.RootCauseRef(
        hypothesis_id=UUID(ranking.root_cause.hypothesis_id),
        evidence_ids=[UUID(r.evidence_id) for r in selected.support_relations],
        final_score=ranking.root_cause.final_score,
    ))
```

### 4.3 root_cause = claim（评审 §root_cause 写 UUID）
```python
# 权威 root_cause 必须是根因描述（claim），而非 hypothesis UUID。
# UUID 只出现在 RootCauseRef.hypothesis_id。
root_cause = None
if ranking.root_cause is not None:
    selected = comp.evaluations[ranking.root_cause.hypothesis_id]
    root_cause = selected.hypothesis.claim          # 或 title，评审确认用 claim
```

### 4.4 hypothesis_scores / contradictions / missing（无损关联）
```python
hypothesis_scores = [
    contracts.HypothesisScore(
        llm_prior=e.score_breakdown.components["llm_reasoning_prior"],
        evidence_support=e.score_breakdown.components["evidence_support"],
        source_reliability=e.score_breakdown.components["source_reliability"],
        temporal=e.score_breakdown.components["temporal_relation"],
        contradiction_penalty=_penalty_sum(e.score_breakdown, {"critical_contradiction", "normal_contradiction"}),
        missing_penalty=_penalty_sum(e.score_breakdown, {"missing_critical"}),
        final_score=e.score_breakdown.final_score,
        hypothesis_id=UUID(e.hypothesis.hypothesis_id),   # 新增关联
    )
    for e in comp.evaluations.values()
]
contradictions = [
    contracts.Contradiction(
        kind=c.contradiction_type, severity=c.severity,
        detail=c.description, resolved=c.resolved,
        hypothesis_id=UUID(c.hypothesis_id), evidence_id=UUID(c.evidence_id) if c.evidence_id else None,
    )
    for e in comp.evaluations.values() for c in e.contradictions
]
missing_evidence = [
    contracts.MissingEvidence(
        kind="critical" if m.critical else "optional",
        reason=m.reason, description=m.required_type,
        hypothesis_id=UUID(m.hypothesis_id),
        required_type=m.required_type, followup_slot=m.followup_slot,
    )
    for e in comp.evaluations.values() for m in e.missing_evidence
]
```

### 4.5 conclusion_state / confidence / status（评审 §supported 丢失）
- `contracts.RcaResult.conclusion_state = comp.conclusion_state`（confirmed/supported/rejected/unknown，权威状态，不再丢失）。
- `confidence = _root_cause_confidence(ranking)` = 被选中 hypothesis 真实 final_score；unknown 时 0.0（§6）。
- `status = "completed" if conclusion_state in ("confirmed","supported") else "unknown"`。

## 5. 状态矩阵（权威 conclusion_state 一致性，新增 validator）

| conclusion_state | root_cause | confidence | root_cause_refs | status |
|------------------|-----------|-----------|-----------------|--------|
| confirmed | claim | final_score(≥0.80) | 必填 | completed |
| supported | claim | final_score(0.60-0.80) | 必填 | completed |
| rejected | None | final_score(<0.60) 或无 | 空 | unknown |
| unknown | None | 0.0 | 空 | unknown |

`contracts.RcaResult.state_matrix` validator：
- confirmed/supported：必须 `root_cause is not None` 且 `root_cause_refs` 非空。
- rejected/unknown：必须 `root_cause is None`。
- confirmed 需 `confidence >= 0.80`；supported 需 `0.60 <= confidence < 0.80`。
- 违规 → `ValueError`（fail-closed）。

## 6. confidence 决策（延续 v0.2.1 §10.2）
`confidence` = 被选中 root_cause hypothesis 的真实 `final_score`（`_root_cause_confidence`）；unknown 时 0.0。**不用枚举映射**（0.90/0.70）进权威层。

## 7. RCA identity（评审 §rca_id 无法区分重评分）
```python
# contracts_identity.py
FROZEN_RCA_NS = UUID("0f1c2a3e-4b5d-4c6e-8f7a-9b0c1d2e3f4a")

def rca_id(run_id, resource_id, snapshot_version) -> UUID:
    """不可变 RCA 实体身份：含 snapshot_version，区分同一 Run/资源的多轮（follow-up/re-score）。

    格式：UUIDv5(FROZEN_RCA_NS, canonical_run_id + NUL + resource_id + NUL + snapshot_version)
    """
    return uuid5(FROZEN_RCA_NS, f"{str(run_id)}\0{resource_id}\0{snapshot_version}")
```
- 同一 Run/资源、snapshot v1/v2 产生**不同** `rca_id`（不可变可复算）。
- **黄金向量**：三端（Python/Go/TS）对固定 `(run_id, resource_id, snapshot_version)` 必须产出一致 `rca_id`；补 `conformance-vectors.json` 条目 + 三端 fixture。

## 8. Evidence 预校验 fail-closed（评审 §跨租户负向）
`RcaEngine.run()/evaluate()` **在创建 snapshot 之前**，逐条校验每个 Evidence 的隔离维度与 Engine 参数一致：
```python
for ev in evidences:
    if ev.tenant_id != self.tenant_id or ev.cluster_id != self.cluster_id or ev.run_id != run_id:
        raise EvidenceScopeMismatch(
            f"Evidence {ev.evidence_id} 隔离维度 (run/tenant/cluster) 与 Engine 不一致 → fail-closed")
```
- 不一致**直接拒绝**（fail-closed），**不是**仅输出 contradiction。
- 负向测试：跨 run/tenant/cluster 的 Evidence 传入 → `EvidenceScopeMismatch`。

## 11. Gate 硬断言

- `RcaEngine.run()` **直接返回 `contracts.RcaResult`**（`isinstance(result, contracts.RcaResult)`）。
- **`rca_engine.py` 不再定义 `class RcaResult`**（grep 0 match）。
- 非零 penalty 通过权威合同（`contradiction_penalty < 0`）且可复算。

- mismatch Evidence 在评分前被拒绝（`EvidenceScopeMismatch`）。
- `rca_production.confidence == contract.confidence`。
- 三端（Schema/Go/TS/fixture/黄金向量）全部进入 Gate。
